As the name of this page suggests, search is the feature in Reconmap that allows you to find projects, tasks, vulnerabilities quickly by only typing part of their name. Type your search term in the search box at the top of the screen and hit enter to see the results.

Matching is case-insensitive and looks at the name of projects and project templates, and at the summary or description of tasks, vulnerabilities and vulnerability templates. Only the matching items are shown in each section; sections with no matches are hidden and listed as "No results were found".

![Search results](/images/screenshots/search-results.png)

## Advanced search

To limit a search to some types of item, open **Search** in the side menu (or go to `/advanced-search`). The advanced search page has two parts:

- **Keywords** and **Search in**: type your search term and tick the types to search: tasks, vulnerabilities, vulnerability templates, projects and project templates. All types are ticked by default. The Search button stays disabled until you enter a keyword and tick at least one type.
- **Recent searches**: the searches you ran recently. Click one to run it again with all types. If you have not searched yet, the section says so. If the list cannot be loaded, the section shows an error message.
