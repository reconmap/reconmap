The **findings** view lists all the findings that were reported by the user or the system (eg automatically after parsing results).

![Findings view](/images/screenshots/findings.png)

The findings list allows presents the following information:

|Summary|Short description of the finding|
|Description|First words from the longer finding description|
|Risk|None, Low, Medium, High, Critical|
|CVSS Score|Common Finding Score System value|
|Category|One of 'Access Controls', 'Auditing and Logging', 'Authentication', 'Configuration', ...|
|Status|- Open (reported, unresolved)<br/>- Confirmed (unexploited, exploited)<br/>- Resolved (remediated, mitigated)<br/>- Closed (remediated, mitigated, rejected)|
|Date/Time|Date and time when the finding was reported|

From this view you can view more details about each finding or delete them if they are no longer applicable.
