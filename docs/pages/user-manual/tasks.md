The tasks view allows you to see tasks across multiple projects. Each one of the rows contains a brief summary of the task, its status, and the project associated to it.

![Tasks](/images/screenshots/tasks.png)

There are filters available on the same screen to narrow down the list to tasks for an specific project, or with an specific status (OPEN or CLOSED).

## Task comments

Open a task and select the **Comments** tab to leave a comment on it, for example to record a blocker or a hand-off note for the next person. Comments work the same way as on projects and vulnerabilities: they support Markdown, are listed newest first, and can be deleted by their author, administrators and superusers. See [Comments](comments.md) for details.
