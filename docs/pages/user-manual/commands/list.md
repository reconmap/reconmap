Reconmap commands are fully defined in code, integrating both the runner definitions (executable path, flags, arguments) and the output parsers directly.

The "Commands Library" has been removed from the user interface, making the system simpler and more reliable. All available commands are directly accessible when running scans once, from a URL, or on a schedule under the **Scans** page. Command usages (specific configurations/arguments) are internal, and which one is executed is decided automatically by the system's LLM.
